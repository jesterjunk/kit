Fonts from X.org

All these fonts come from the X.org server distribution. You can download all of these as Rockbox FNT, BDF versions are available from freedesktop.org cvs. These fonts are all found in the Debian distribution of X.org, so I assume they are DFSG free.

If you want a particular font in BDF format, you can email me and I will send it.
