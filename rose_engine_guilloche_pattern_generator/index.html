The OBJ exporter sweeps a rounded single-point cutter along the actual generated toolpath. Cut width is calculated from cutter geometry and penetration depth. Non-overlapping cuts use path-aligned quad strips; overlapping cuts are combined as Boolean material removal, where the deepest cutter envelope wins at every point on the surface.

3D export notes The OBJ is an open surface (a true displaced plane), not a watertight solid. The default Cinema 4D orientation places the design in the XZ plane with depth along Y. The default OBJ mesher follows the toolpath with quad strips rather than cutting grooves through a rectangular grid. Auto-smooth increases sampling along those toolpath-aligned strips. In Cinema 4D you can add Cloth Surface / Extrude / Volume Builder if you need thickness. OBJ units are numeric millimeters; set the import scale accordingly if your Cinema 4D project uses another unit.
